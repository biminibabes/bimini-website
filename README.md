# BIMINI Website

Your personal website - owned, controlled, and updated by you.

## 🎨 Features

- Neon acid punk aesthetic with hot pink, neon yellow, and orange
- Responsive design (works on all devices)
- Laylo mailing list integration
- Easy to update - just edit the HTML files
- No build tools required

## 📁 Files

- `index.html` - Main website file
- `styles.css` - All the styling and colors
- `script.js` - Navigation and interactive features
- `README.md` - This file

## ✏️ How to Update Content

### Update Tour Dates
1. Open `index.html`
2. Find the section with `id="tour-section"`
3. Add your tour dates in the `.tour-content` div
4. Save and push to GitHub

### Update Music
1. Open `index.html`
2. Find the section with `id="music-section"`
3. Add your latest releases, Spotify embeds, etc.
4. Save and push to GitHub

### Change Colors
1. Open `styles.css`
2. Edit the color variables at the top:
   ```css
   --hot-pink: #FF1493;
   --neon-yellow: #CCFF00;
   --orange: #FFA500;
   ```

## 🚀 Deployment

This site is deployed on Vercel. Any changes you push to GitHub will automatically update the live site within seconds.
