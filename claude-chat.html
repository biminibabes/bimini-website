Connect a Claude session

Every message you send publishes a new version of this page. A Claude session watching the page is woken by that publish, reads your message, and publishes its reply into the chat — so replies work from any surface.

Claude Cowork or claude.ai/code: paste this page's link into a session and say:

Watch this artifact and reply to new chat messages in it: [page link]

Terminal Claude Code: run claude in your terminal and give it the same instruction with the link.

The whole conversation lives in this page, so history follows the link wherever you open it.
